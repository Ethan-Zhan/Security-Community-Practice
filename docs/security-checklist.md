# 安全审查清单 (security-checklist.md)

本清单用于对“GitHub Actions 自动签到日志安全加固”任务的代码改动进行安全自审，确保敏感数据不发生日志泄漏。

| 编号 | 安全审查检查项 | 检查状态 (Y/N/不适用) | 审查/审计说明 |
| :--- | :--- | :--- | :--- |
| **1** | **敏感凭证绝无直接硬编码**<br>代码和注释中绝对没有出现明文的 Cookie、Token、API Key 或测试账号密码。 |  | *(等待代码生成后人工核对并填写)* |
| **2** | **统一输出通道管理**<br>所有控制台日志输出是否都重定向或使用了安全的包装打印函数（如 `safe_print`），而不是随意调用原生 `print()`？ |  | *(等待代码生成后人工核对并填写)* |
| **3** | **响应内容（response.text）安全处理**<br>当第三方请求失败、报错或状态码非 200 时，是否拒绝直接调用 `print(response.text)`？是否做好了异常内容的清洗与截断？ |  | *(等待代码生成后人工核对并填写)* |
| **4** | **异常捕获报错（Exception）安全脱敏**<br>在所有 `except Exception as e` 语句中，是否移除了 `print(e)` 这种高危的默认打印？是否仅输出自定义安全报错提示？ |  | *(等待代码生成后人工核对并填写)* |
| **5** | **动态黑名单字符串遮罩**<br>脱敏逻辑是否能够动态读取环境变量（如 `ALPHAGEN_COOKIE` / `CREATIVEHUB_AUTH`）的值，并在将任何日志打印到控制台之前，进行动态替换（遮罩为 `[REDACTED_SECRET]`）？ |  | *(等待代码生成后人工核对并填写)* |
| **6** | **调试/临时日志彻底清理**<br>代码中是否没有任何用于临时排查问题的 `print(request.headers)` 等高风险残留？ |  | *(等待代码生成后人工核对并填写)* |
