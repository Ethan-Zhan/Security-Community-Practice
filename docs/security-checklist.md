## 使用说明

本文件用于对 AI 修改结果进行两层检查：

1. 对照 Prompt 检查：确认 AI 是否真的完成要求，而不是只写注释或解释。
2. 人工安全审查：确认认证、授权、输入校验、数据写入和错误响应是否符合预期。
