## 一、 背景说明与开发范围
*   **开发背景**: 本项目是将一个本地的基于卷积神经网络（CNN）的手写数字图像分类脚本升级为一个对外部提供 Web API 的生产服务。
*   **开发范围**: 仅限于 `成员代码/王彦杰-Image Classification using CNN` 目录。严禁在未经授权的情况下增改、读取或分析其他任何组员的项目文件夹。

---

## 二、 核心安全约束条件 (无条件执行)

### 1. 【安全控制点 - 身份认证约束】
*   **要求**: 所有开放的图像推理接口（如 `/api/predict`）必须是**需要身份验证才能访问的功能接口**。
*   **编码准则**: 
    - 必须从请求头中提取 `Authorization: Bearer <API_KEY>`。
    - 严禁提供任何后门或者免签访问。如果 Key 不正确，一律返回 `401 Unauthorized` 状态码，并附带明确的错误信息。

### 2. 【安全控制点 - 输入文件名保护（防目录穿越）】
*   **要求**: 必须对用户上传的文件名进行强力的过滤与消毒，防范路径遍历攻击（Path Traversal）。
*   **编码准则**:
    - 必须使用 Python `werkzeug.utils.secure_filename` 函数对上传文件名进行标准化过滤。
    - 严禁直接使用用户传入的原始字符串进行物理路径拼接或磁盘写操作。

### 3. 【安全控制点 - 上传体积与速率防御（防 DoS 攻击）】
*   **要求**: 限制文件最大体积为 2MB，从源头上切断恶意的大文件占满物理磁盘或内存攻击。
*   **编码准则**:
    - 必须配置 Flask `app.config['MAX_CONTENT_LENGTH'] = 2 * 1024 * 1024`。
    - 服务必须能捕获并优雅处理 `413 Request Entity Too Large` 的全局报错，统一返回格式化 JSON 应答，不得直接抛出服务器 Crash。

### 4. 【安全控制点 - 二进制数据流安检（防图片木马）】
*   **要求**: 绝对不能仅仅通过文件名后缀（.png/.jpg）来判断文件是否安全。必须分析文件底层的二进制图像结构，防御图片中混入恶意 WebShell 可执行脚本。
*   **编码准则**:
    - 必须在数据预处理前，使用 Python 的 `PIL.Image.open()` 尝试读取底层二进制结构并执行 `img.verify()`。
    - 一旦检测到图片文件结构受损、非真实图片或加载异常，必须立即进行拦截，记录高危审计日志并返回 `400 Bad Request`。

### 5. 【安全控制点 - 堆栈报错防护（防敏感泄露）】
*   **要求**: 隐藏后端真实物理盘符、服务器文件树、Python 库版本等敏感系统结构信息。
*   **编码准则**:
    - 接口代码必须包含一个全局错误处理拦截（如使用 try-except 包裹全部处理流程，或利用全局异常捕获装饰器）。
    - 严禁在返回结果中直接打印 `traceback.format_exc()` 或异常对象的原始描述 `str(ex)`。一律向外部客户端返回规范的掩码错误描述（如 `{'success': False, 'message': 'Internal error occurred'}`）。

## 三、 禁止行为列表 (AI Code Redlines)
1.  **禁止行为 1**: 严禁在接口中使用硬编码的零防护文件写入机制（如 `open(filename, 'wb')` 而不经过 secure_filename 过滤）。
2.  **禁止行为 2**: 严禁允许匿名调用分类服务。
3.  **禁止行为 3**: 严禁生成不带任何环境兼容的、非此即彼的强制导入代码。当 TensorFlow 缺失时，必须能自适应降级到安全模拟模式运行，以方便本地无配环境下的顺畅测试与验证。
