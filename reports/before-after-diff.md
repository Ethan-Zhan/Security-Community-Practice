## ⚖️ 重构前后核心架构与逻辑差异

| 维度对比 | 重构前 (Before) | 重构后 (After) | 安全增益效果 |
| :--- | :--- | :--- | :--- |
| **网络暴露与鉴权** | 纯本地单机运行，无网络鉴权。若直接 Web 化，任何人都可以免登录匿名调用该高性能算法，耗尽 CPU 算力。 | 暴露 Flask 接口，强制实施基于 Header 的 API Key 鉴权：`Authorization: Bearer BUPT_SEC_2026_TEST_KEY`。 | **消除了未授权访问漏洞**。确保只有授权用户/系统可调用核心 CNN 推理算力。 |

| **报错堆栈泄露保护**| 本地运行若出现报错，直接由终端打印输出完整的 Traceback 调试堆栈、库版本和本地物理绝对路径。 | 全局捕获 `try-except` 推理和输入异常。捕获后统一返回 Mask 遮罩后的规范 JSON，屏蔽内部盘符路径。 | **保护敏感系统拓扑信息**。切断黑客搜集服务器底层物理架构和系统漏洞情报的渠道。 |
| **测试与可移植性** | 强依赖极其庞大、配置极易出错的 TensorFlow、Keras 解释器及 CUDA 驱动环境。 | 内置**环境自适应降级模式**。缺失 TensorFlow 时自动以沙箱 Mock 演示，所有安全拦截机制 100% 真实起效。 | **极大降低了演示和迁移成本**。用户及老师验证仅需数秒安装微型库，极速体验并验证全部安全拦截功能。 |

### 1. 图像对接预处理与安全管道
*   **重构前**: 直接对下载好的测试集进行 Numpy 转换：
    ```python
    # imageClassification.py: L31-37
    train_images = train_images.astype('float32') / 255.0
    train_images = train_images.reshape((-1, 28, 28, 1))
    ```
*   **重构后**: 先对外部上传的二进制文件流进行 Pillow 木马和受损拦截，再在内存中执行灰度转换、28x28 像素缩放、255.0 归一化与维度重塑，实现安全的输入规范化与模型对接：
    ```python
    # secure_classification_api.py: L133-149
    # (1) 图片二进制流安全verify安检
    img = Image.open(file.stream)
    img.verify()
    file.stream.seek(0)

    # (2) 预处理数据对接
    img = Image.open(file.stream)
    img_gray = img.convert('L')         # 转换为单通道灰度
    img_resized = img_gray.resize((28, 28))  # 缩放到 28x28 像素
    
    # [模型推理对接]
    img_array = np.array(img_resized).astype('float32') / 255.0
    img_input = img_array.reshape((1, 28, 28, 1))
    ```
