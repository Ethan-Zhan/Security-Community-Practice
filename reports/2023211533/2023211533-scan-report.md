## 扫描方法

使用以下命令对全部20关进行安全漏洞扫描：

```bash
# 1. 检查无过滤直接输出的危险模式
grep -n 'echo.*\$_[A-Z]' 漏洞靶场/level*.php | grep -v 'htmlspecialchars'

# 2. 检查str_replace黑名单过滤
grep -n 'str_replace' 漏洞靶场/level*.php

# 3. 检查htmlspecialchars使用是否规范
grep -n 'htmlspecialchars' 漏洞靶场/level*.php | grep -v 'ENT_QUOTES'

# 4. 检查安全响应头配置
grep -n 'header\s*(' 漏洞靶场/level*.php

# 5. 检查错误是否泄露
grep -n 'display_errors' 漏洞靶场/level*.php

# 6. 检查危险函数使用
grep -rn 'eval\|system\|exec\|shell_exec\|passthru' 漏洞靶场/
```

