# 风险识别：用户注册与登录模块

## 涉及接口
- `POST /register` - 用户注册
- `POST /login` - 用户登录

## 主要安全风险

### 1. 凭证存储风险
- **风险描述**：密码若以明文或弱哈希（如MD5/SHA1）存储，数据库泄露后可被彩虹表批量破解
- **影响范围**：用户密码安全、账户凭证泄露
- **缓解措施**：使用 `pbkdf2:sha256` 加盐哈希，salt长度≥16字节

### 2. 账户枚举风险
- **风险描述**：注册/登录失败时若返回"邮箱已存在""密码错误"等具体提示，攻击者可批量探测有效账户
- **影响范围**：用户隐私泄露、撞库攻击前置条件
- **缓解措施**：统一返回 `{"success": false, "message": "注册失败/登录失败"}`，不暴露字段级状态

### 3. 暴力破解风险
- **风险描述**：无频率限制时，攻击者可脚本化尝试密码撞库或批量注册垃圾账户
- **影响范围**：服务可用性、账户安全
- **缓解措施**：注册接口限流 `5/min`，登录接口限流 `10/min`，配合429错误处理器

### 4. 注入与输入风险
- **风险描述**：用户输入若直接拼接SQL或执行，可导致数据泄露/篡改；非法格式输入可能绕过业务逻辑
- **影响范围**：数据库完整性、业务逻辑安全
- **缓解措施**：使用 SQLAlchemy ORM（自动参数化）+ 正则校验用户名/邮箱/密码格式

### 5. 信息泄露风险
- **风险描述**：错误堆栈/调试信息/响应头若暴露服务器版本或路径，可被用于定向攻击
- **影响范围**：攻击面扩大
- **缓解措施**：`debug=False` + 全局 `after_request` 注入安全响应头（`X-Frame-Options`/`X-Content-Type-Options`等）
