# 项目安全约束文档（AI交互必读）

> 📌 使用说明：每次开启新AI对话时，**首条消息完整粘贴本文档**，确保约束持续生效

## 项目背景
正在开发用户认证模块（注册+登录），基于 Flask + SQLAlchemy + SQLite，需严格遵循安全开发规范。

## 强制约束条件

### 数据存取安全
- ✅ 必须使用 SQLAlchemy ORM 或参数化查询，**严禁字符串拼接SQL**
- ✅ 数据库敏感字段（如密码）禁止明文存储

### 凭证处理安全
- ✅ 密码必须使用加盐哈希算法：接受 `pbkdf2:sha256` / `bcrypt` / `argon2`
- ✅ salt长度 ≥ 16 字节，迭代次数使用框架默认安全值
- ✅ 密码比对必须使用 `check_password_hash()` 等恒定时间算法，**防时序攻击**

### 输入校验规则
```regex
用户名: ^[A-Za-z0-9_]{6,20}$
邮箱:   ^[^@\s]+@[^@\s]+\.[^@\s]+$
密码:   ^(?=.*[a-z])(?=.*[A-Z])(?=.*\d).{8,}$
